Agrivision – Crop and Weed Detection

>>Project Overview
Agrivision is a deep learning-based project that detects and differentiates crops and weeds from agricultural images using YOLOv8.

 Objectives
- Automatically detect crops and weeds.
- Identify weed-affected regions.
- Reduce manual effort in weed identification.
- Support smart agriculture.

 Technologies Used
- Python
- YOLOv8
- PyTorch
- OpenCV
- Google Colab

Dataset
The dataset was collected from Kaggle and used for training and testing the detection model.
1. Dataset collection from Kaggle.
2. Image preprocessing and annotation.
3. Training the YOLOv8 model.
4. Detecting crops and weeds.
5. Displaying results using bounding boxes.

# Output
- Green bounding boxes indicate crops.
- Red bounding boxes indicate weeds.

# Platform
Google Colab
